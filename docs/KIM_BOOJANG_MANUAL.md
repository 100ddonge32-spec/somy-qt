## 🏗️ 2. 소미 큐티 앱 (Somy QT) 현재 개발 상태 요약

### 🛠️ 기술 스택 (Tech Stack)
* **프론트엔드:** Next.js (App Router), React, Tailwind CSS
* **백엔드/DB:** Supabase (PostgreSQL), Next.js API Routes (Edge / Node)
* **AI 연동:** OpenAI API (GPT-4o) - 담임목사 칼럼 자동 생성, 큐티 질문 생성, 기도문 작성
* **배포 환경:** Vercel (Pro Plan 유지 중)
* **주요 패키지:** `lucide-react` (아이콘), `next-pwa` (홈 화면 아이콘 설치 기능)

### 🚀 핵심 구현 완성 기능
1. **PWA 웹앱화:** 크롬/사파리를 통해 스마트폰 '홈 화면에 추가' 기능 완벽 구현.
2. **소미(Somy) 마스코트 도입:** 딱딱한 신앙 앱이 아닌 트렌디하고 귀여운 UI/UX (Sanctuary UI) 적용.
3. **사용자 권한 계층:** 
   * `super_admin`: 백동희 대표님 (시스템 전체 수정, 마스터 권한)
   * `church_admin`: 각 교회 담임목사/관리자 (자신의 교회 정보와 성도만 관리 가능)
   * `user`: 승인된 일반 성도 (개인 큐티, 감사일기 열람/작성)
   * `guest`: 미승인 방문자 (샘플 큐티만 열람 가능, 기능 제한)
4. **멀티테넌시(Multi-tenancy) 지원:** 주소창에 `?church_id=예수인교회` 처럼 입력 시 해당 교회 전용 로고, 성도 목록, 글이 완전히 분리되어 노출. (id 1번은 예수인교회 하드코딩 보호)
5. **AI 담임목사 기능:** 오늘의 말씀(네비게이토 60구절 또는 관리자가 커스텀한 구절)을 기반으로, AI가 500자 내외의 은혜로운 '담임목사 칼럼' 및 '묵상 질문 3가지', '오늘의 기도'를 자동 생성.
6. **동적 설정(Settings) 관리:** 관리자 패널에서 교회의 기본 정보(이름, 로고), 행사 포스터 타이머 팝업 노출, 오늘의 말씀 강제 고정 기능 등을 관리자가 직접 설정 가능. (DB 컬럼을 늘리지 않고 `plan` 필드 파싱 압축 기술로 데이터 부담 제로)
7. **유튜브 백그라운드 재생(CCM):** 안드로이드/아이폰 화면이 꺼진 상태에서도 찬양이 끊기지 않고 재생되도록 MediaSession API 및 Watchdog 타이머 적용.

## 🛡️ 3. 해결된 치명적 트러블슈팅 (역사적 사건)

### 🚨 Vercel 요금 폭주 (Infinite Loop) 사태 완전 진압
* **증상:** 배포 후 1~2일 만에 Vercel Edge Requests 490만 번, Function Invocations 540만 번이 찍히며 요금제 무료 한도를 500% 이상 초과하는 대형 사고 발생.
* **원인:** `page.tsx` 내 푸시 알림 권한 체크 함수(`subscribePush`)가 매 렌더링마다 갱신되며, 상태 갱신 $\to$ 리렌더링 $\to$ 통신 $\to$ 팝업 확인을 무한 반복하는 '무한 루프(Infinite Loop)'가 돌고 있었음. 또한, `middleware.ts`에서 정적 이미지 파일 등을 걸러주지 않아 텍스트 하나, 사진 하나 뜰 때마다 엣지 로드가 걸림.
* **해결 및 방어:**
  1. `subscribePush`에 `useCallback` 접착제를 강하게 발라 무한 렌더링 차단. 미승인 시 15초, 승인 시 10분으로 통신 빈도 억제.
  2. `middleware.ts`의 정규식(`matcher`)을 손상시켜 사진, 서비스워커가 불필요한 과금을 낳지 않도록 차단.
  3. Vercel 고객센터를 이메일로 설득 및 미납청구서 락 수동 해제, $20 과금 중 $19.35(100% 가까이) 환불을 성사시킴! 현재 **안정적인 Pro 요금제 플랜**으로 1개월 유지 적용 완료. 트래픽 증발 이슈 완전 종결.

## 📁 4. 주요 핵심 파일 위치

* `src/app/page.tsx`: 앱의 90% 이상을 구동하는 핵심 심장부 (UI, 큐티, 알림, 관리자 뷰).
* `src/middleware.ts`: 접속하는 URL에 따라 `church_id`를 헤더에 박아주는 수문장.
* `src/app/api/settings/route.ts`: 앱 옵션, 오늘의 말씀 커스텀, AI 칼럼 등을 DB와 싱크 맞추고 압축 저장하는 고도화 서버 로직 위치.
* `src/app/api/auth/sync/route.ts`: 구글/카카오 로그인 연동 후, DB(`profiles`)에 데이터를 매칭시키고 관리자 권한을 부여하는 인증 핵심 로직.
* `src/lib/navigator-verses.ts`: 네비게이토 핵심 암송 60구절 배열 목록.
